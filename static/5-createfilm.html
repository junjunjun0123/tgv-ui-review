Create film · title request

A film must exist as a Vista title before anyone can rate it. Name the film, tick the experiences it plays in, and one title is generated per experience — [IMAX2D] DOOMSDAY, [BEANIE] DOOMSDAY and so on.

◆
Business rule: the rating queue opens only for titles created here. Each experience is a separate rateable title, so the IMAX and Beanie versions of the same film carry their own four programmer scores.

A film title request is raised once by Admin or Creator. Programmers and viewers sign in and work from the same Vista titles — so everyone rates and schedules the same version of the film.

  • Admin opens every module and can publish titles.
  • Creator publishes new titles for the slate.
  • Programmer rates the created titles and builds the schedule.
  • Viewer reads the ratings and the plan.
